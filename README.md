# File Handling Utility

## Description
This project is a Java File Handling Utility program developed as part of the CODTECH Internship Task 1.

The program demonstrates basic file operations in Java:
- Writing data into a text file
- Reading data from a text file
- Modifying an existing text file

---

## Features
- Create and write content into a file
- Read and display file content
- Append new content to existing file
- Simple and easy-to-understand code
- Proper comments included in program

---

## Technologies Used
- Java
- File Handling
- Scanner Class
- FileWriter Class

---

## Files Included

1. FileHandlingUtility.java  
   Main Java program for file handling operations.

2. sample.txt  
   Text file generated after program execution.

3. README.md  
   Project documentation file.
