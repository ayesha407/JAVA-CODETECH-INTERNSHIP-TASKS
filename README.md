# CODTECH Java Programming Internship

## Overview

This repository contains all four tasks completed as part of the **CODTECH Java Programming Internship**. The projects demonstrate core Java concepts including file handling, REST API integration, multithreading with networking, and GUI application development.

# Tasks Completed

## Task 1 – File Handling Utility

### Description

Developed a Java application that performs basic file operations such as:

* Writing data into a file
* Reading data from a file
* Modifying existing file content

### Concepts Used

* File Handling
* Exception Handling
* Scanner Class
* Java I/O Streams

### Output

The program creates and manages a text file named:

```text
sample.txt
```

---

## Task 2 – REST API Client

### Description

Developed a Java REST API Client that fetches data from a public API and displays the response in the console.

### Features

* Connects to a REST API
* Sends HTTP GET requests
* Reads JSON responses
* Displays fetched data

### Concepts Used

* HTTPURLConnection
* BufferedReader
* InputStreamReader
* JSON Data Handling

---

## Task 3 – Multithreaded Chat Application

### Description

Developed a client-server chat application using Java Sockets and Multithreading.

### Features

* Multiple clients can connect to the server
* Real-time messaging
* Separate threads for handling communication
* Client-server architecture

### Concepts Used

* Socket Programming
* ServerSocket
* Multithreading
* Networking

### Project Files

```text
ChatServer.java
ChatClient.java
```
