# File Handling Utility in Java

## Overview

This project is a Java-based File Handling Utility developed as part of **CODTECH Internship - Task 1**.

The application demonstrates basic file operations in Java, including:

* Writing data into a text file
* Reading data from a text file
* Modifying existing file content

The program uses Java File Handling concepts and provides a simple menu-driven interface for user interaction.

---

## Objectives

The objective of this project is to understand and implement:

* File creation and management
* Reading data from files
* Writing data to files
* Modifying existing file content
* Exception handling in Java
* User interaction using Scanner class

---

## Features

### Write Data to File

Allows users to enter text and store it in a file.

### Read File Content

Displays the contents of the file on the console.

### Modify File Content

Replaces the existing content of the file with new content entered by the user.

### Exception Handling

Handles file-related errors gracefully.

### Menu-Driven Interface

Provides an easy-to-use console menu for performing operations.

---

## Technologies Used

* Java
* File Handling (FileWriter, FileReader, BufferedReader)
* Exception Handling
* Scanner Class
