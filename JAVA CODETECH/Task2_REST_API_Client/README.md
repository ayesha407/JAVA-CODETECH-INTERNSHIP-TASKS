# REST API Client - Weather Application

## Description
This project is a Java REST API Client developed as part of the CODTECH Internship Task 2.

The application connects to the OpenWeatherMap public REST API, fetches weather data for a city, and displays the response in JSON format.

---

## Features
- Connects to a public REST API
- Sends HTTP GET request
- Fetches live weather data
- Displays JSON response
- Demonstrates API integration using Java

---

## Technologies Used
- Java
- REST API
- HTTPURLConnection
- BufferedReader
- OpenWeatherMap API
